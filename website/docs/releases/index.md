# Release history {.ignore-header}

Run `packageVersion("languageserver")` in the R installation your editor uses, then select that version in the page outline. If you installed from GitHub or r-universe, your build may share a version number with a release. [Check which build is installed](../guide/troubleshooting#a-development-example-is-missing)

The development section lists changes since the latest release. For hands-on examples, see the [feature reference](../reference/capabilities) and [development guide](../guide/development).
